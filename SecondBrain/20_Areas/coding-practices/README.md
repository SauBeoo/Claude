# 20_Areas/coding-practices — Kinh nghiệm coding cá nhân

Note ở đây là **kinh nghiệm của tôi** rút ra qua project thật, không phải lý thuyết copy từ blog.

## Khi nào note vào đây?

- ✅ "Lần này tôi nhận ra X — sẽ áp dụng cho các project sau"
- ✅ Quy tắc cá nhân tôi tự đặt cho mình khi viết code
- ✅ Pattern tôi *đã thử* và rút ra kết luận
- ✅ Anti-pattern tôi đã vấp và muốn không vấp lại

## Khi nào KHÔNG note vào đây?

- ❌ Tóm tắt 1 blog "10 best practices" → `30_Resources/web-development/` (hoặc tương đương)
- ❌ Khái niệm trừu tượng dùng được nhiều lần → `50_Atomic/concepts/`
- ❌ Ghi chú đang debug 1 bug cụ thể → `10_Projects/<X>/notes/`

## Phân biệt với Atomic notes

Areas note = "kinh nghiệm vai trò" (mang giọng tôi, gắn context cá nhân).
Atomic note = "tri thức tái sử dụng" (mang tính khái niệm, dùng cho người khác đọc cũng hiểu).

→ Nếu thấy Areas note dần đủ "chín" để dùng dạy/viết content → có thể *promote* thành atomic ở `50_Atomic/`.
