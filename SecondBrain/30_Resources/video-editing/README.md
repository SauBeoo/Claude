# 30_Resources/video-editing — Tài liệu làm video

Note ở đây là **kỹ thuật, preset, tutorial dựng video** của người khác — không phải video bạn đang làm.

## Khi nào note vào đây?

- ✅ Tutorial Premiere/DaVinci/CapCut hay đáng revisit
- ✅ Preset color grading, sound design, motion graphics đã lưu
- ✅ Phân tích style của 1 channel (cinematography, pacing)
- ✅ Cheat sheet shortcut, workflow tutorial

## Khi nào KHÔNG note vào đây?

- ❌ Bạn đang LÀM video → `10_Projects/video-series-<X>/outputs/`
- ❌ Kinh nghiệm cá nhân khi edit (pattern bạn rút ra) → `20_Areas/content-creation/`
- ❌ Khóa edit dài → `30_Resources/courses/`

## Cấu trúc thư mục con (nếu cần)

Khi note nhiều, tạo subfolder:
```
video-editing/
├── premiere/
├── davinci/
├── capcut/
├── thumbnails/

```
