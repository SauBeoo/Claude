# 60_Daily — Daily note

Mỗi ngày 1 file `YYYY-MM-DD.md`. Đây là nơi:
- Bắt đầu ngày: list việc cần làm
- Trong ngày: quăng vào những thứ chợt nghĩ
- Cuối ngày: nhìn lại

## Tổ chức

```
60_Daily/
└── 2026/
    ├── 05/
    │   ├── 2026-05-23.md
    │   └── 2026-05-24.md
    └── 06/
```

Obsidian có plugin **Daily Notes** + **Calendar** giúp tự tạo file đúng vị trí. Cấu hình:
- Date format: `YYYY-MM-DD`
- New file location: `60_Daily/YYYY/MM/`
- Template file: `99_Meta/templates/daily.md`

## Daily không phải Journal cá nhân

Daily ở đây = nhật ký công việc. Nếu muốn journal cảm xúc/sức khỏe → tạo thêm thư mục `70_Journal/` riêng (không sync GitHub).

## Khi nào "chắt lọc" Daily?

Cuối tuần lướt qua 7 daily notes:
- Có ý tưởng nào lặp lại 2+ lần? → có thể đáng tạo atomic note
- Có insight nào mới? → atomic note
- Có việc dang dở? → đưa vào project tương ứng
