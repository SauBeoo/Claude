# 3 chế độ Claude Desktop — Chat, Cowork, Code

Tưởng tượng cùng một người đồng nghiệp siêu giỏi, nhưng bạn mời họ ngồi ở 3 cái bàn khác nhau tuỳ việc:

- **Chat** — đồng nghiệp *ghé qua bàn hỏi 1 câu*. Hỏi nhanh, brainstorm, nháp ngắn. Bạn lái từng bước, output là text/1 artifact, xong trong vài giây–phút.
- **Cowork** — đồng nghiệp *nhận nguyên một project cả tuần*. Bạn đưa mục tiêu → họ tự lập kế hoạch, tự chạy (đẻ subagent), trả về sản phẩm hoàn chỉnh trong folder. Việc tri thức dài hơi: research, đọc 50 tài liệu, soạn report.
- **Code** — đồng nghiệp *lập trình viên* làm phần mềm thật: đọc/sửa code, chạy test, commit git.

Cả 3 dùng **cùng một trí tuệ Claude**, chỉ khác giao diện và quyền hạn. Nguyên tắc thiết kế: mỗi mode hiện đúng thứ quan trọng cho loại việc đó — không "one size fits all".
