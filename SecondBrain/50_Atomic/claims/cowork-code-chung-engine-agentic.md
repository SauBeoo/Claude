# Luận điểm: Cowork và Code là anh em ruột — cùng engine agentic

Cowork (cho người làm tri thức) và Code (cho dev) trông như hai thứ khác hẳn nhau, nhưng **chạy trên cùng một engine: Claude Code**. Hệ quả: "làm việc dài hơi" — dù là viết phần mềm hay rà 50 hợp đồng — về bản chất là *cùng một loại công việc agentic*: chia nhỏ task → tự chạy nhiều bước → gọi subagent song song → dùng tool → kéo dài hàng giờ.

## Lập luận ủng hộ

- Anthropic lấy chính bộ máy agent của Claude Code, khoác giao diện thân thiện người-không-code → ra Cowork. Cùng máy, khác mặt tiền.
- Bằng chứng "di truyền": subagent, "duyệt plan trước khi chạy", "xin phép trước khi đụng" xuất hiện y hệt ở cả Cowork lẫn Code.

## Lập luận phản biện

- Chúng vẫn khác về *phạm vi & quyền*: Cowork chỉ folder bạn share (contained), Code có full project (file system, terminal, git). Chung engine ≠ chung quyền hạn.

## Quan điểm của tôi

Tin cao. Đây là góc nhìn giúp người đã rành Claude Code học Cowork rất nhanh — không phải học lại từ đầu, chỉ là cùng bộ máy đặt trong hộp an toàn hơn.
