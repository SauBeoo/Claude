# Loom Script — Web Scraper Demo (~60 seconds)

> Quay màn hình + giọng nói (tiếng Anh). Mục tiêu: khách thấy INPUT → CHẠY → OUTPUT.
> Đừng đọc như robot, nói tự nhiên. Dưới đây là dàn ý + lời thoại gợi ý.

## Chuẩn bị màn hình
- Mở 2 cửa sổ cạnh nhau: (1) trang web books.toscrape.com, (2) terminal
- Có sẵn file `products.xlsx` để mở khoe cuối video

## Kịch bản

**[0-10s] Vấn đề**
> "Say you need all the products from a website — names, prices, ratings — but copying them by hand would take hours. Here's how I automate that."

*(Cuộn nhanh trang web cho thấy nhiều sản phẩm)*

**[10-30s] Chạy script**
> "I just run one command, tell it how many pages, and where to save."

*(Gõ trong terminal:)*
```bash
python scraper.py --pages 3 --out products.xlsx
```
> "It walks through each page, handles pagination automatically, and cleans up duplicates."

*(Cho thấy log [page 1], [page 2], [page 3]... rồi [OK] Exported)*

**[30-55s] Kết quả**
> "And here's the result — a clean Excel file."

*(Mở products.xlsx)*
> "Every product with its title, price, rating, availability, and a direct link. Sorted, numbered, ready to use. No copy-paste, no errors."

**[55-60s] CTA**
> "If you've got a website you need data from, send me the link and I'll turn it into a spreadsheet like this. Thanks for watching!"
