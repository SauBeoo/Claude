# Portfolio Demo — Làm để chứng minh năng lực (không cần khách thật)

> Vấn đề con gà & quả trứng: chưa có job → chưa có portfolio → khó có job.
> Giải: TỰ làm 2-3 demo nhỏ trong vài buổi tối. Đây là khoản đầu tư đáng giá nhất tuần 1.

## Demo 1 — Web Scraper (1-2h)
**Làm gì:** Scrape một site công khai (vd: books.toscrape.com, quotes.toscrape.com — site được tạo riêng để luyện scraping, hợp pháp 100%) → xuất Excel sạch.

**Trưng bày:**
- Ảnh chụp file Excel kết quả (đẹp, có header rõ)
- Đoạn code Python ngắn trên GitHub
- Loom 60s: "đây là input, chạy script, đây là output"

**Tiêu đề portfolio:** "E-commerce Product Scraper → Clean Excel Export"

## Demo 2 — Google Sheets Automation (1-2h)
**Làm gì:** Một Google Sheet mẫu: khi đánh dấu một dòng "Done", tự động gửi email xác nhận + ghi timestamp. Hoặc: tự tổng hợp dashboard từ data thô.

**Trưng bày:**
- GIF/Loom: tick ô → email bay đi
- Link sheet demo (chế độ view)

**Tiêu đề:** "Auto-Email & Dashboard Automation with Apps Script"

## Demo 3 — API Integration (2-3h)
**Làm gì:** Script lấy data từ một API miễn phí (vd thời tiết, tỷ giá, GitHub) → đẩy vào Google Sheet hoặc gửi Slack/Telegram mỗi sáng.

**Trưng bày:**
- Sơ đồ luồng đơn giản (API → script → Sheet/Slack)
- Loom demo chạy thật

**Tiêu đề:** "Automated Daily Report: API → Google Sheets"
