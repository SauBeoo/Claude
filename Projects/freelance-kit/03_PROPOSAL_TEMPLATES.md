# Proposal Templates (Upwork Cover Letter)

> Quy tắc vàng: **2-3 câu đầu PHẢI cá nhân hóa** theo đúng job đó. Client đọc 5s đầu để quyết định. Bot/copy-paste lộ liễu → bỏ qua ngay.
> Giữ NGẮN. Client ghét đọc dài. ~120-180 từ.

---

## Template A — Web Scraping job

```
Hi [Name],

I can scrape [specific site/data they mentioned] and deliver it as a clean [Excel/CSV] with exactly the fields you listed: [field 1, field 2, ...].

I've done similar scrapes — I handle pagination and de-duplication so you get clean, usable data, not a mess.

Quick question so I quote precisely: roughly how many records / pages are we looking at, and do you need this as a one-time pull or recurring?

I can start today and deliver a sample of the first ~20 rows so you can confirm the format before I run the full job.

Best,
[Your name]
```

---

## Template B — Google Sheets / Automation job

```
Hi [Name],

You want to [restate their goal in one line, e.g. "auto-send a reminder email when a row hits 'overdue'"] — that's a clean fit for Google Apps Script and I can build it.

Here's how I'd approach it:
1. [step 1 specific to their case]
2. [step 2]
3. Add a [trigger/button] so it runs automatically.

I'll include a short Loom video showing how to use it, so you're not dependent on me afterward.

One thing to confirm: [a smart clarifying question about their setup].

Happy to start right away.

[Your name]
```

## Template C — Generic automation / script job

```
Hi [Name],

This is exactly the kind of repetitive task worth automating. From your description, I'd build a [Python script / small tool] that [does X automatically].

I'm a software engineer — you'll get clean, documented code plus a walkthrough video, not a black box.

Before I quote, one question: [clarifying question, e.g. "is the source data always in the same format?"].

I can deliver the first working version within [X] days and iterate from there.

Best,
[Your name]
```

## Checklist trước khi gửi mỗi proposal

- [ ] Đã đọc KỸ job post chưa? (nhiều client cài "từ khóa bí mật" để lọc bot — vd "start your reply with the word BANANA")
- [ ] 2 câu đầu nhắc đúng chi tiết job của HỌ chưa?
- [ ] Có 1 câu hỏi thông minh thể hiện đã hiểu vấn đề chưa?
- [ ] Ngắn gọn (<180 từ) chưa?
- [ ] Đề xuất bước tiếp theo cụ thể (sample, start today) chưa?
- [ ] Không sai chính tả / xưng hô đúng tên client chưa?

## Lọc job NÊN gửi (tiết kiệm Connects)

✅ Payment verified
✅ Có hire history + review tốt
✅ Budget rõ ràng & hợp lý
✅ Job mới đăng (<24h)
✅ Mô tả rõ ràng (client biết họ muốn gì)

❌ Tránh: "I need everything for $10", job đăng đã lâu 50+ proposal, client mới toanh chưa verify, mô tả mơ hồ 1 dòng.
