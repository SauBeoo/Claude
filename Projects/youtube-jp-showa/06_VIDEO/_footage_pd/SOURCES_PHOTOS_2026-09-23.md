# Free-for-commercial REAL photos, Japan 1946–1974 — sources (2026-09-23)

Method: Wikimedia Commons API (file search + category crawl of "Japan/Tokyo in the 1940s–70s", photographer categories Domon / Kimura / Tanuma / Hayashi / Hamaya, the wilford peloquin 1971 Flickr set, David Pirmann "Found Photo" set). License re-read per file from **imageinfo extmetadata + the license templates actually transcluded on the file page** (column "license"). Nothing downloaded. Images were **not viewed** — "what it shows" is from title/description; eyeball before use.

Rules applied: only PD / CC0 / CC BY / CC BY-SA; NC / ND / unknown rejected; >=1000 px wide (a few 1000–1300 px, flagged).

Caveats:
- PD-Japan-oldphoto = PD in Japan (photo taken before 1946, or published before 1957 under the old law). Commons accepts it; US status can differ (URAA). Keep the credit line anyway.
- PD-Japan-organization = organisation work, 50 years after publication.
- CC BY / BY-SA: credit required (概要欄 / ATTRIBUTIONS.md) with license name + link.
- US National Archives catalog: its API now needs a key (v2 returned the web app, not JSON), so NARA was only covered via Commons imports; nothing relevant surfaced (mostly military/occupation).
